# 📚 LibTrack – Library Management System

LibTrack is a simple terminal-based Library Management System built using **Python only**. It helps manage books, borrowers, book availability, and issue/return records.

## 🚀 Features

- 115+ Preloaded Books with Authors
- View All Books
- Search Books by Name or Author
- Issue Books to Borrowers
- Return Issued Books
- Store Borrower Details
- Track Issue and Return Dates
- View Issued Book Records
- Library Statistics
- Automatic Data Storage using JSON

## 🛠️ Technologies Used

- Python
- JSON
- Datetime Module

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Run the program:
   ```bash
   python libtrack.py
   ```

## 📂 Project Structure

```text
LibTrack/

```

*Note: `libtrack_data.json` is automatically created when the program runs.*
